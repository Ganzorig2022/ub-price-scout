# УБ Үнэ Тандагч

Facebook зарын текст, нийтэд нээлттэй холбоос эсвэл дэлгэцийн зургаас бараа болон зарын үнийг ялгаж, Улаанбаатарын онлайн дэлгүүрүүдийн үнэтэй харьцуулах Монгол веб апп.

## Гол боломжууд

- Facebook зарын текстээс барааны нэр, үзүүлэлт, үнийг автоматаар ялгана.
- Нийтэд нээлттэй Facebook холбоосын metadata-г аюулгүй, хязгаартай байдлаар уншихыг оролдоно.
- Дэлгэцийн зургийн текст танилт нь хөтөч дотор `mon` + `eng` хэлээр ажиллана; зураг сервер рүү илгээхгүй.
- Ялгасан мэдээллийг хэрэглэгч шалгаж, засварласны дараа л дэлгүүрүүдээс хайна.
- 15 эх сурвалжийг зэрэг шалгана — дэлгүүр бүрийг өөрийнх нь бодит өгөгдлийн замаар уншина (`lib/sources/`):
  - **Cody платформ** (iTStore, PC Mall, TurboTech, Next Electronics, Gadget.mn, CityMall Computer) — дэлгүүрийн хуудас өөрөө ашигладаг нийтэд нээлттэй `guest` Elasticsearch хайлт.
  - **Zochil платформ** (SEGU, BedRock) — `/search?name=` хуудасны `__NEXT_DATA__`.
  - **WooCommerce Store API** (x86, uTech) — нийтэд нээлттэй JSON.
  - **Best Computers** — хайлтын цонхны JSON autocomplete. **iPick**, **PC-Mall.mn** — серверээс ирсэн HTML/stream.
  - **Arina**, **Unegui** — мэдэгдэж буй өгөгдлийн зам байхгүй; ихэвчлэн «уншигдаагүй»/«хаалттай» гэж шударгаар тэмдэглэнэ, холбоос нь нээлттэй.
- Дэлгүүр бүрийн бодит хариултаас авсан fixture дээр parser-ийн тест ажиллана (`npm run test:unit`). Дэлгүүр хуудсаа өөрчилбөл тухайн тест улаан болно.
- Яг ижил болон төстэй барааг тусад нь харуулж, бодит үнийн хүрээ болон дүгнэлт гаргана.
- Барааны identity token давхцаагүй бол `2`, `Pro`, үнэ зэрэг ерөнхий token-оор хуурамч match үүсгэхгүй.
- Хайлтад ороогүй хувилбар (`Pro`, `FE`, `Ti`, `Plus` …) гарчигт байвал «яг ижил» гэж тооцохгүй; дагалдах хэрэгсэл (наалт, гэр, цэнэглэгч) гарчиг эсвэл холбоосоор нь хасагдана; дунджаас 60%-иас илүү хямд «яг ижил» бараа сэжигтэй гэж төстэй рүү шилжинэ.
- Богиносгосон хайлтын хувилбараар олсон ч гэсэн барааг хэрэглэгчийн бүтэн хайлттай харьцуулж дүгнэнэ.
- JavaScript каталогийг уншиж чадаагүй тохиолдлыг “бараа байхгүй” гэж буруу дүгнэхгүй.
- BedRock болон бусад баталгаажсан худалдааны хуудсын Facebook хайлтыг тусдаа, баталгаажаагүй lead хэлбэрээр нээнэ; эдгээрийг үнийн дундажт оруулахгүй.
- PWA болгон суулгасны дараа Facebook-ийн Share цэснээс текст, холбоосыг шууд Үнэ Тандагч руу дамжуулна.
- D1-д share хийх боломжтой тайлан хадгална.
- **Facebook группийн 2-р гар зар**: хэрэглэгч өөрийн нэвтэрсэн хөтчөөс bookmarklet дарж, дэлгэц дээр харагдаж буй постуудыг апп руу илгээнэ (`lib/facebook-collect.ts`). Постын текст серверт хадгалагдахгүй; ижил барааны 2-р гар үнийн хүрээг дэлгүүрийн дундажаас тусад нь харуулна.
- Цагийн хязгаар хэрэглэгч тус бүрээр (IP-ийн давсалсан hash) + сайтын нийт дээд хязгаар (`lib/rate-limit.ts`): хайлт 20/цаг/хэрэглэгч, 400/цаг нийт.

## Facebook-ийн хязгаарлалт

Bookmarklet (`lib/facebook-collect.ts` дахь `BOOKMARKLET_SOURCE`) зөвхөн `facebook.com` дээр, хэрэглэгч дарах бүрд л ажиллана. Facebook-ийн хуудасны хамгаалалт гадны скрипт болон `fetch` дуудлагыг хаадаг тул энгийн form POST-оор `/share` руу илгээнэ; холбоосоос tracking параметрүүдийг хаяж зөвхөн постын id-г үлдээнэ. Автомат цуглуулалт нь Facebook-ийн үйлчилгээний нөхцөлд харшилж болзошгүй тул хэрэглэгч өөрийн account-ийн эрсдэлийг өөрөө хариуцна.


Facebook нэвтрэлт шаардсан, хаалттай group/Marketplace эсвэл автомат хандалтыг хаасан постыг серверээс баталгаатай унших боломжгүй. Facebook lead товч нь хайлтыг хэрэглэгчийн нэвтэрсэн төхөөрөмж дээр нээхээс биш үр дүнг scrape хийсэн гэсэн үг биш. Ийм үед Share ашиглах, зарын текстийг хуулж тавих эсвэл дэлгэцийн зургаас текст таниулна. Апп Facebook-ийн хамгаалалтыг тойрч гарахгүй.

## Privacy

- Дэлгэцийн зураг төхөөрөмжөөс гарахгүй.
- Бүтэн зарын текст D1-д хадгалагдахгүй.
- Тайланд зөвхөн баталгаажуулсан барааны query, үнэ болон цэвэрлэсэн Facebook холбоос хадгалагдана.
- Facebook URL fetch нь зөвхөн тогтсон Facebook host, HTTPS, стандарт port, дахин шалгагдсан redirect, 1MB response cap, 6 секундийн timeout ашиглана.

## Local development

Node.js `>=22.13.0` шаардлагатай.

```bash
npm ci
npm run dev
npm run lint
npx tsc --noEmit
npm test
```

`npm test` нь production build үүсгээд SSR, intake extraction, URL boundary, persistence болон scanner registry-г шалгана. `npm run test:unit` нь build-гүйгээр зөвхөн эх сурвалжийн parser-уудыг шалгана.

## Deployment

Апп Vinext/Cloudflare Workers, D1, Drizzle ашиглана. Хоёр зам:

**Өөрийн Cloudflare account (одоогийн live зам).** D1 database нэг удаа үүсгээд migrations-ийг гараар ажиллуулна, дараа нь build-ийн үед database id-г өгч deploy хийнэ:

```bash
npx wrangler d1 create ub-price-scout
npx wrangler d1 execute ub-price-scout --remote --file drizzle/0000_huge_grey_gargoyle.sql
npx wrangler d1 execute ub-price-scout --remote --file drizzle/0001_past_psynapse.sql
D1_DATABASE_ID=<id> D1_DATABASE_NAME=ub-price-scout npm run build
npx wrangler deploy
```

**OpenAI Sites (хуучин зам).** `.openai/hosting.json` дахь project болон D1 binding-г өөрчлөхгүйгээр `sites` remote руу push хийнэ; database id-г Sites control plane өөрөө тавина.
