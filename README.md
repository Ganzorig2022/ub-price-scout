# УБ Үнэ Тандагч

Facebook зарын текст, нийтэд нээлттэй холбоос эсвэл дэлгэцийн зургаас бараа болон зарын үнийг ялгаж, Улаанбаатарын онлайн дэлгүүрүүдийн үнэтэй харьцуулах Монгол веб апп.

## Гол боломжууд

- Facebook зарын текстээс барааны нэр, үзүүлэлт, үнийг автоматаар ялгана.
- Нийтэд нээлттэй Facebook холбоосын metadata-г аюулгүй, хязгаартай байдлаар уншихыг оролдоно.
- Дэлгэцийн зургийн текст танилт нь хөтөч дотор `mon` + `eng` хэлээр ажиллана; зураг сервер рүү илгээхгүй.
- Ялгасан мэдээллийг хэрэглэгч шалгаж, засварласны дараа л дэлгүүрүүдээс хайна.
- Best Computers, iTStore, SEGU, PC Mall, iPick, TurboTech, Arina, BedRock, Unegui-г шалгана.
- Яг ижил болон төстэй барааг тусад нь харуулж, бодит үнийн хүрээ болон дүгнэлт гаргана.
- JavaScript каталогийг уншиж чадаагүй тохиолдлыг “бараа байхгүй” гэж буруу дүгнэхгүй.
- D1-д share хийх боломжтой тайлан хадгална.

## Facebook-ийн хязгаарлалт

Facebook нэвтрэлт шаардсан, хаалттай group/Marketplace эсвэл автомат хандалтыг хаасан постыг серверээс баталгаатай унших боломжгүй. Ийм үед зарын текстийг хуулж тавих эсвэл дэлгэцийн зургаас текст таниулна. Апп Facebook-ийн хамгаалалтыг тойрч гарахгүй.

## Privacy

- Дэлгэцийн зураг төхөөрөмжөөс гарахгүй.
- Бүтэн зарын текст D1-д хадгалагдахгүй.
- Тайланд зөвхөн баталгаажуулсан барааны query, үнэ болон цэвэрлэсэн Facebook холбоос хадгалагдана.
- Facebook URL fetch нь зөвхөн тогтсон Facebook host, HTTPS, стандарт port, дахин шалгагдсан redirect, 1MB response cap, 6 секундийн timeout ашиглана.

## Local development

Node.js `>=22.13.0` шаардлагатай.

```bash
npm ci
npm run dev
npm run lint
npx tsc --noEmit
npm test
```

`npm test` нь production build үүсгээд SSR, intake extraction, URL boundary, persistence болон scanner registry-г шалгана.

## Deployment

Апп Vinext/Cloudflare Workers, D1, Drizzle болон OpenAI Sites hosting ашиглана. `.openai/hosting.json` дахь Sites project болон D1 binding-г өөрчлөхгүйгээр build archive-д migrations багтана.
